File Permissions
----------------

Read - 4
write - 2
execute - 1
total 7

ex :  -rw-r--r--

 (-) denotes it is file (if its starts with drw- --> then its a directory)

1)-rw- > who is the onwer of the file also called as user has read and write permission == (u)
2)r-- > which group he belongs to has only read permission == (g)
3)r-- > others has only read permission ==(o)

*Who can change permissions? either owner/root user/ admin

*command to change permission chmod

chmod o+w filename (giving others write permission) (002)
chmod o+x filename (giving others execute permission)(001) 
chmod o-rwx filename (removing rwx permission to others) (000)
chmod ugo+rwx filename (adding all permissions to all users, group, others) (777)

* if you don't assign any group to user. His group is also same as his username 
( ex: -rw-r--r--. 1 ec2-user ec2-user 1519 Jan 30 06:43 passwd - Here ec2-user didnt tagged to anygroup so his username and group name is same i.e ec2-user)

777 - means all access to everyone -rwxrwxrwx
750 - means user has all access, group has read and execute access and 0 access for others  -rwxr-x---

Foreground and background process:
-----------------------------------

Foreground -->Runs in foreground, Blocks the screen while running
background --> runs in background, you can do other works

How can you run a process in background?

give & after command.

ex: sleep 10 (it will run for 10 seconds but blocks the screen since it was foreground process)

sleep 100 & (Now it will run for 100 seconds in background without blocking the screen)

ex:

[root@ip-172-31-19-0 ~]# sleep 10

[root@ip-172-31-19-0 ~]# sleep 10 &
[1] 5531
[root@ip-172-31-19-0 ~]# ps -ef|grep sleep
root        5531    5141  0 15:05 pts/1    00:00:00 sleep 10
root        5582    5141  0 15:05 pts/1    00:00:00 grep --color=auto sleep
[root@ip-172-31-19-0 ~]#
